# BsAutoRec
Automatic OBS recording control for BS

## 概要

- 曲プレイが始まるとOBSの **録画を開始** し、曲が終わると **録画を停止** します。
- 録画を終了すると、指定した名前テンプレートに従って、指定のフォルダに **リネームして保存** します。
- OBSは **websocketで** 制御します。
- ゲームのイベントは **websocketで** 取得します。そのため、タイミングには **多少のディレイ** があります。
- 本アプリはインターネット通信を **行いません** 。

## 動作環境
- **.NET 10** ランタイムが必要です。
- ゲーム本体とOBSが **ローカルPC上で** 動作している環境を想定しています。
- **WebSocket v5** 対応バージョンのOBSが必要です。
- ゲーム本体で、以下の **MODを有効に** してください。
  - HttpSiraStatus

## インストール
zipを展開して適当なフォルダに置いてください。そこがインストールフォルダになります。

BsAutoRec.exeを実行して起動できます。

## 使い方
- アプリ初回起動時は、 **設定欄** を開いて、最低限以下の設定をしてください。
  - ゲームのwebsocket接続先
  - OBSのwebsocket接続先/パスワード
  - 録画ファイルのリネーム先 (指定しないときは、OBSの録画ファイル出力先と同じフォルダ)

- 設定完了後、 **開始ボタン** を押してください。
  または、アプリ起動時に自動開始オプションもあります。
  動作を止めたいときは、 **停止ボタン** を押してください。

- アプリは、状態を **色やテキストで** 表示したりログを出したりしているので、雰囲気で挙動をつかんでください。
